# Owner Part 4 — standalone departments and integrated boundaries

## Implemented
- All fourteen subscribed/permitted departments appear in Department Workspaces. Each shows its input/output boundary, instead of depending on an unlicensed neighbouring department.
- Core Fabric/Cutting/Elastic/Accessories/Delivery support externally referenced stock receipt/handover using existing ERP SKUs, SKU units, reviewed total inventory value, counterparty and three-decimal quantities (whole pieces for piece units).
- Core integrated same-SKU handoff supports Fabric → Cutting and Cutting/Elastic/Accessories → Delivery. Quantities/value move together atomically. This is physical transfer, not a fabric-to-garment conversion; existing production and consumption workflows remain responsible for conversion.
- Delivery writers can send Delivery finished-piece stock into a stitching lot/bundle. Existing reviewed Cutting/Finished stock and linked legacy-challan paths remain available.
- Standalone Stitching, Inward, Checking, Ironing, Packing, Dispatch, Warehouse and Shop can receive appropriate externally supplied garment stages. Only completed output is eligible for external handover; Shop uses normal sales rather than a generic external stock sale.
- Stitching requires its own operation master; it no longer requires a packing master when Packing is not subscribed. Packing can attach its own master at pack entry. Packing-only workspaces can receive local materials without an Accessories licence, then consume actual material stock.
- Standalone Inward records partial DC receipt into INWARD_READY if Checking is not subscribed; pending quantity remains sent minus received. Ironing users can see and start GOOD bundles without Checking permission. Rework can be handed externally to Stitching when that department is not subscribed; waste remains under the existing disposal approval path.
- Integrated Dispatch/Warehouse transfers reject unsubscribed destinations. External receipt/output is denied where its corresponding upstream/downstream neighbour is subscribed. Optional Elastic/Accessories supplies retain independent external boundaries.
- Marketing-only workspaces can record separately identified external sales observations and obtain a demand suggestion. These observations do not manufacture retail sales, invoices or stock movements. Existing internal sales analysis remains separate.
- Boundary postings use existing factory-scoped transaction/idempotency controls and posted stock/journal ledgers. Duplicate reference/SKU postings with different retry keys are rejected. External custody values post balanced INVENTORY/EXTERNAL_CLEARING journals, with no implicit purchase invoice or payment.
- Administrators can reverse unused boundary receipts/transfers through the existing explicit UNDO MOVEMENT flow, with a reason and original department permission. Subsequent destination stock movement blocks reversal; bundle stock must be untouched. Original records remain with reversal links; references cannot be reused.
- Department screens include core balances, receipt/handoff history, local packing material and external marketing forms. Warehouse/shop receipts require existing assigned location masters.

## Operating prerequisites
Company/factory setup, reviewed ERP activation, existing SKU masters and granted department permissions are required. Stitching needs an operation master; Packing needs a packing master plus real material stock; Warehouse/Shop need assigned location masters. Registered physical-roll SKUs must use their existing physical-roll workflows rather than generic core stock receipt/transfer. Generic core receipts do not create roll QR records.
Use a reference unique per SKU and receipt/handoff in the factory (for example vendor/DC/line). A partial return or another handover needs its own reference. Review total inventory value and custody clearing with the accountant; this is not automatic supplier invoicing, cost certification, tax determination or accounts-payable settlement.
